
Agricultural Output by State — Power BI Capstone Project

An interactive Power BI dashboard analyzing agricultural output, crop losses, and crop performance across states in Nigeria.

Project Overview

This capstone project focuses on analyzing agricultural production data to identify patterns in crop output, losses, and performance across different Nigerian states.

The dashboard provides an interactive way to explore agricultural data and supports data-driven decision-making in crop production and planning.

Project Objectives.

Analyze agricultural output by state.

Compare the performance of major crops.

Identify crop losses and loss rates.

Explore agricultural production patterns.

Present key findings through an interactive Power BI dashboard.

Tools & Technologies

Power BI — Data visualization and interactive dashboard

Microsoft Excel — Dataset preparation and analysis

Power Query — Data cleaning and transformation
